# Monthly Performance Calendar

A responsive, single-file calendar card inspired by the supplied dark UI reference.

## Features

- Compact 10-day view for November 11–20, 2026
- Animated expand/collapse into a full 6-week monthly calendar
- Yellow progress line with $1400 and $2000 labels
- Silver total badge ($2440)
- Positive, negative, and neutral daily values
- Future dates are visually subdued
- Keyboard support: press Escape to collapse
- Responsive layout and reduced-motion support

## Run locally

Open `index.html` in a modern browser. No build step or dependencies required.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will publish the site at:

https://romanbali.github.io/sendbox/
